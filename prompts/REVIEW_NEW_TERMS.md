# Review New Terminology

Inspect the requested source and translation for important terminology not yet approved in `glossary/GLOSSARY.md` or the relevant domain glossary.

Identify the domain and language pair. Do not consult an unrelated domain glossary, and do not modify any approved glossary automatically.

For each unresolved term provide:
- source term;
- domain and language pair;
- source context;
- current translation;
- existing glossary entry, if any;
- proposed handling;
- Preserve / Translate / Needs expert decision;
- reason.

Do not establish new terminology as canonical without explicit user approval.

Record unresolved items in `glossary/TERM_DECISIONS.md`. After explicit user approval, add the decision to `GLOSSARY.md` if it is cross-domain or to the appropriate domain glossary if it is subject-specific.
