# Gemini Workspace Bootstrap

This repository is a controlled general-purpose translation workspace for any subject, genre, document type, and language pair.

`AGENTS.md` is the authoritative repository instruction.

Before any translation, chunking, revision, or QA task:

1. Read and follow `AGENTS.md`.
2. Read `glossary/GLOSSARY.md`.
3. Read only the domain glossaries relevant to the source, if any.
4. Consult `glossary/TERM_DECISIONS.md` when terminology is unresolved.
5. Consult `reference/APPROVED_TRANSLATIONS.md` when relevant.
6. Never overwrite a file under `source/`.
7. Use the task-specific file under `prompts/` when the user names one or when its workflow clearly applies.

Do not duplicate or override the repository rules unless the user explicitly instructs you to do so.
